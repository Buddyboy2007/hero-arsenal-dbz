Every character installed

1,675 spawnable characters across 164 addons — every nextbot and SNPC the install can put on a map, read out of the entity declarations in the .gma archives themselves. The 66 Dragon Ball fighters are not repeated here; they have their own roster, because they are the only ones the band ladder reaches.

Found by what a class inherits, not by what it is called — a pack's own template sits between its characters and the framework, so the chain has to be walked. Anything another class is built on top of is dropped as a base rather than counted as a fighter.

  • DrGBase — 914 characters. Built on DrGBase, the nextbot framework the Dragon Ball fighters themselves run on.
  • VJ Base — 760 characters. VJ Base SNPCs — the older engine-NPC lineage, registered into the NPC tab by VJ Base rather than by a Spawnable flag.
  • Nextbot — 1 character. A plain base_nextbot, built on neither framework.
