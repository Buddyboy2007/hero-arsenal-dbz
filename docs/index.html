The full roster

Sixty-six fighters on one power ladder. Every figure below is read out of the running install — band, scaling, and each character's own named arsenal, including the moves they only throw as AI.

Band

A band is a fighter's rung on the power ladder — a whole number from 0 to 30, and the only thing the game reads when it decides how strong a character is. Nothing else is tuned by hand: every band up multiplies both damage and health by about 1.41×, so two bands is exactly double. The tier letter is just a label for a range of bands.
