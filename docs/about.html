How this page knows

Nothing here is maintained by hand. A build step reads the Garry's Mod install directly, every ten minutes, and this site is whatever it found.

Three sources, three methods

The twelve Hero Arsenal heroes are read out of the workshop .gma archives. Each hero file is a single RegisterHeroJSON([=[ … ]=]) call, so the definition is already JSON — parsed exactly, never guessed at. Only the lua/hero_arsenal_dbz/heroes/ entries are read, which is what keeps the step from pulling two hundred megabytes of models per item.

The 54 Tenkaichi fighters are obtained by executing z_dbz_bt3.lua under a stub harness and dumping its tables. Pattern-matching the file would have missed the entire forms layer — the Kaioken climbs, the Cooler and Frieza ladders, the per-character dispatch — because those are built by code, not written as data.

The tier maths is lifted off the literals in server/z_dbz_fighters_ai.lua. If one of those is ever renamed the build reports it as an error rather than quietly publishing a wrong number.

The scaling, exactly as the game applies it

A fighter's band is the only input — if that word is new, the tier page explains it in full. Everything else follows from it:

  • rating = 2 ^ band, capped at 1e+03T.
  • Health is multiplied by rating ^ 0.5, then clamped to 1,000,000,000 — the ceiling the engine's integer health field imposes.
  • Damage is multiplied by rating ^ 0.5.

Those two exponents matching is the whole point. Both sides of a fight grow at the same rate, so a band-28 bout lasts about as long as a band-4 one — it just has far bigger numbers floating over it.

Why some moves look like they belong to someone else

A Tenkaichi fighter borrows its arsenal from one of the twelve donors, and takes whichever power ids its roster row asks for. Moves the donor flags disabled or hidden are still copied across, and are shown here, because the player's wheel is the only thing those flags gate. The AI cast path never checks them — it asks only whether the hero owns the power. These fighters really do throw them, so hiding them would describe a roster the game does not have.
